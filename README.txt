RAW DEF Calculator — pacote PWA preparado para PWABuilder

Arquivos:
- index.html
- manifest.json
- sw.js
- icons/ (192, 512, 1024 e maskable)
- screenshots/ (1080x1920)

Como usar:
1. Substitua os arquivos da raiz do seu repositório GitHub pelos deste pacote.
2. Envie também as pastas icons e screenshots mantendo os nomes.
3. Faça Commit changes.
4. Aguarde o GitHub Pages atualizar.
5. Rode novamente a URL no PWABuilder.

O manifest inclui descrição, ID, orientação portrait, escopo, ícones e screenshot.
