Política de Privacidade — RAW DEF ROOC

Última atualização: 7 de setembro de 2026

O RAW DEF ROOC é uma calculadora independente e fan-made desenvolvida para auxiliar jogadores na realização de cálculos relacionados a PDEF e MDEF.

1. Coleta de dados

O RAW DEF ROOC não coleta, armazena ou envia dados pessoais dos usuários.

Os valores inseridos nos campos da calculadora são processados localmente no dispositivo exclusivamente para realizar os cálculos solicitados.

O aplicativo não exige:

  • cadastro ou criação de conta;
  • nome;
  • endereço de e-mail;
  • número de telefone;
  • localização;
  • senha;
  • informações de pagamento.

2. Compartilhamento de dados

O RAW DEF ROOC não compartilha dados pessoais dos usuários com terceiros.

Os valores inseridos na calculadora não são enviados para servidores externos pelo aplicativo.

3. Armazenamento

O aplicativo não mantém um banco de dados de informações pessoais dos usuários.

Os valores digitados nos campos da calculadora são utilizados durante a utilização do aplicativo e podem ser apagados pelo próprio usuário por meio da função LIMPAR.

4. Área de transferência

O aplicativo possui uma função que permite copiar os resultados calculados para a área de transferência do dispositivo.

Essa função é acionada voluntariamente pelo usuário por meio do botão COPIAR RESULTADOS. O RAW DEF ROOC não utiliza a área de transferência para coletar ou transmitir informações.

5. Serviços de terceiros

A versão atual do RAW DEF ROOC não utiliza serviços de terceiros destinados à coleta de dados pessoais, publicidade personalizada ou análise de comportamento do usuário.

6. Segurança

Como o aplicativo não transmite dados pessoais para servidores externos, não existe um banco de dados do RAW DEF ROOC contendo informações pessoais dos usuários.

7. Privacidade de crianças

O RAW DEF ROOC não solicita informações pessoais e pode ser utilizado sem criação de conta ou fornecimento de dados pessoais.

8. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada caso sejam adicionadas novas funcionalidades ou modificadas as práticas de tratamento de dados do aplicativo. Quando houver alterações relevantes, a data de atualização desta política será modificada.

10. Projeto independente

O RAW DEF ROOC é um projeto independente e fan-made. O aplicativo não é oficial e não possui vínculo, patrocínio, autorização ou afiliação com desenvolvedores, publicadoras ou detentores de direitos de propriedade intelectual de jogos eventualmente mencionados ou relacionados ao seu uso.

O objetivo do aplicativo é exclusivamente oferecer uma ferramenta de cálculo e auxílio aos jogadores.
